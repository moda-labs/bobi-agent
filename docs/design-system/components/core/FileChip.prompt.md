Names a real file inline. Bobi's config is its interface, so this chip shows up in headings, body copy, tables, and inspectors.

```jsx
<h3>Give it <FileChip inHeading>workflows/</FileChip>, not vibes.</h3>
<p>Secrets live in <FileChip>.env</FileChip>.</p>
<FileChip accent>support-triage.yaml</FileChip>
```
