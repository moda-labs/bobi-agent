Opens an editorial or marketing section. Label in CAPS, short — 1-4 words.

```jsx
<Eyebrow>THE LOOP</Eyebrow>
<h2>One queue. One director. <span className="bobi-hi">The whole team.</span></h2>
```

The square is clay because it is decorative. In product UI, use the quiet,
sentence-case `SectionLabel` instead.
