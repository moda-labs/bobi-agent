The Bobi button — one primary violet action per view, everything else quiet.

```jsx
<Button variant="primary" size="lg" icon={<Icon name="github" />}>View on GitHub</Button>
<Button variant="ghost">Cancel</Button>
<Button variant="glass" as="a" href="#">Read the docs</Button>
```

Variants: `primary` (violet, the action) · `inverse` (paper on dark imagery) · `quiet` (tan secondary) · `glass` (over photography) · `ghost` (bordered, low-stakes).
Sizes: `sm` 14px chrome · `md` 15px default · `lg` 17px hero.
