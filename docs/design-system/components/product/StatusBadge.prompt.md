The state of a run, an agent, or a monitor.

```jsx
<StatusBadge state="live" />
<StatusBadge state="waiting" label="awaiting approval" />
<StatusBadge state="done" />
```

Fixed meanings: **live** violet (the system is working) · **waiting** clay (a person is the blocker) · **done** ink · **idle** muted · **failed** brick.
